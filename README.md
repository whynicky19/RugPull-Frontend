# Rugpull — Frontend


> ИИ-сканер токенов: анализ контракта, on-chain данных, соцсетей и китов за 30 секунд.

---

## О проекте

**Rugpull** — веб-приложение для проверки криптовалютных токенов на признаки мошенничества (rug pull, honeypot и др.).

**Что анализируется:**

| Детектив | Что проверяет |
|---|---|
| Контракт | Опасные функции в смарт-контракте |
| On-chain | Распределение токенов, ликвидность, держатели |
| Соцсети | Упоминания в Telegram, активность сообщества |
| Киты | Концентрация токенов у крупных кошельков |

**Итог:** общий риск-скор от 0 до 100 + AI-вердикт.

---

- **[Nuxt 3](https://nuxt.com/)** — фреймворк (Vue 3 + SSR)
- **TypeScript**

## Требования

- Node.js **18+**
- npm / yarn / pnpm
- Запущенный бэкенд (по умолчанию на `http://localhost:8000`)

---

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone https://github.com/whynicky19/RugPull-Frontend.git
cd rugpull-frontend
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Настроить переменные окружения

Скопировать пример и при необходимости изменить URL бэкенда:

```bash
cp .env.example .env
```

`.env`:
```env
API_BASE=http://localhost:8000
```

### 4. Запустить в режиме разработки

```bash
npm run dev
```

Приложение будет доступно по адресу **http://localhost:3000**

## Структура проекта

├── pages/

│   ├── Verdict.vue        # AI-вердикт

## Как использовать

1. Откройте **http://localhost:3000**
2. Введите адрес токена в формате `0x...`
3. Нажмите **СКАНИРОВАТЬ**
4. Получите результат: риск-скор, детализацию по 4 факторам, AI-вердикт и список угроз
